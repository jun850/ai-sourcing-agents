# Atelix agent intake playbook

1. Run deterministic route classification before retrieval or inference.
2. If unclassified, ask whether the request is finished goods, CMT, fabric, leather, or trims.
3. Use only the selected route's concise requirements. Do not load unrelated knowledge.
4. Save only explicit universal RFQ facts. Keep item-specific details scoped to their item.
5. Retrieve only buyer-safe, published route-specific guidance. Do not expose source paths or internal procedures.
6. The model drafts and clarifies; guarded Supabase operations own persistence, access, supplier, invoices, and payment truth.

## Outcome labels
An operator may approve a de-identified learning record once there is reviewed lifecycle evidence. Record completeness gaps, corrections, retrieval versions, latency, and milestone labels. Never store raw prompts, attachments, buyer identity, supplier identity, prices, invoice values, or payment references.
