# Atelix category requirement matrix

Use this guide only to identify the next missing buyer requirement. Do not turn
an optional detail into a supplier claim or an artificial blocker.

| Category | Capture first | Useful next detail |
| --- | --- | --- |
| Apparel | item, quantity/unit | material/construction, sizes/colors, reference |
| Footwear | item, quantity/unit | material/construction, size range, reference |
| Bags/accessories | item, quantity/unit | material, dimensions, reference |
| Jewelry | item, quantity/unit | material, finish, dimensions |
| Beauty/personal care | product direction, quantity/unit | packaging and stated compliance requirement |
| Home textiles | item, quantity/unit | material, dimensions, reference |
| Fibre/yarn | composition, quantity/unit | yarn type/count, intended use |
| Fabric | fibre/composition, quantity/unit | construction, weight, width, intended use |
| Leather | type, quantity/unit | thickness, finish, dimensions, intended use |
| Interlining | material, quantity/unit | construction, weight, width, fusible/sew-in |
| Trims/labels | component, quantity/unit | material, dimensions, function, finish |
| Packaging | component, quantity/unit | material, dimensions, print/finish, branding |

If an RFQ contains multiple items, keep the requirements scoped to the relevant
line item. Do not combine a fabric width with the finished garment item.
