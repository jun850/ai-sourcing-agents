# Japan routing playbook

Use Japan only when the vetted supplier record supports the requested production route. The current private network is strongest in approved fabric records, with apparel and accessories also represented.

- Route: fabric-led work and apparel/accessory requests whose supplier tags, type, and evidence match the RFQ.
- Buyer fit: buyers prioritising a specific evidenced material, construction, or production capability.
- Price-sensitive briefs: never assume an order is unsuitable or expensive; require current comparable quotes.
- Ops checks: confirm technical feasibility, MOQ, lead time, certification, and export terms with the supplier.
