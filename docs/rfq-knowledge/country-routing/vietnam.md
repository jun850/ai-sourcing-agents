# Vietnam routing playbook

Use Vietnam only when the vetted supplier record supports the requested production route. The current private network has approved apparel, knitwear, and sportswear capability records.

- Route: apparel CMT/OEM/ODM and knitwear or sportswear where the selected supplier's tags and evidence match the RFQ.
- Buyer fit: apparel briefs with an evidenced production-mode match.
- Price-sensitive briefs: a candidate's stored MOQ can help comparison, but price remains unknown until a supplier quote is reviewed.
- Ops checks: confirm capacity, MOQ, lead time, certifications, availability, and terms with the supplier.
